# 対外・対内直接投資（国別・業種別、年次）

| 項目 | 内容 |
|---|---|
| 作成 | 日本銀行・財務省（国際収支統計の関連統計） |
| 掲載ページ | https://www.mof.go.jp/policy/international_policy/reference/balance_of_payments/bpfdii.htm |
| ファイル | `revised/fdiYYYY.xlsx`（シート3：対外 国別・業種別、シート4：対内 国別・業種別） |
| 期間 | 2020〜2025年（このページに掲載されている年） |
| 単位 | 億円。**ネット（実行−回収）**。暦年 |
| 取得スクリプト | `scripts/mof_fdi_by_country.py`（`openpyxl==3.1.5`） |
| 加工データ | `data/processed/mof_fdi_by_country.csv`（年×方向×国×業種） |

## 利用規約
財務省サイトのコンテンツとして **公共データ利用規約（第1.0版）（PDL1.0）**。加工・商用利用可、出典の記載が必要。
> 出典：財務省・日本銀行「対外・対内直接投資（地域別・業種別）」を加工して作成

## 列の定義
- `direction`：`outward`＝対外直接投資（日本の企業などが外国へ）、`inward`＝対内直接投資（外国から日本へ）
- `value_oku_yen`：ネット（投資の実行 − 回収）。マイナスは回収が上回った（引き揚げが多かった）こと
- `status`：`ok` 数値／`confidential`（X：報告3件未満で秘匿）／`none`（．：該当なし）。秘匿・該当なしは空欄のまま（埋めない）
- 業種：製造業（計）・非製造業（計）とその内訳、合計

## 検算
各年・各方向で、国の「合計」の和が、シート1・2の「全世界」合計と一致することを確認（`.meta.json` の `world_vs_listed`）。

## 言えること・言えないこと
**言えること**：日本の企業などが、その年にどの国へ（ネットで）どれだけ直接投資したか。どの国から日本へ来たか。
**注意**
- **親子関係原則**で集計。関連会社から親会社への投資を「回収」として計上するため、国際収支統計の直接投資（資産負債原則）とは一致しない（元データの注記）。
- **ネット**なので、大きな投資と大きな引き揚げが同じ年にあると小さく見える。
- 国は投資先の**直接の相手国**。オランダやシンガポールなど、地域統括会社・持株会社を経由した投資は、最終的な事業の場所とは限らない。
- 年次。2025年分は今後の年次改訂で変わりうる（改訂は raw のスナップショットで残る）。
- 月次・2014年以降の国別データは日本銀行 API にあるが、利用条件（商用・改変）を日本銀行に確認中のため未使用。
