# MABUI

**見えざる手を、見る。**

MABUI（マブイ）は沖縄の言葉で「魂」。

一人ひとりの意思は小さい。けれど人が集まり、組織になり、国になり、国同士がつながると、
お金・投資・物の価値・人の移動は「個人の顔」を失い、独自の意思を持つ巨大な生き物（超個体）のようにうごめき始める。

MABUI は、その生き物に宿る魂を **信用できる公共データ** だけを使って観測する装置です。

## 目的
- 世界に目を向け、世の中や人の動きに興味を持つ人を、一人でも増やす
- 誰もが信用して使える、出典の追えるデータを作り、公開する

## 原則
- **何を描くかはデータが決める。どう描くかはアートが決める。**
- 画面上のすべての動きは、タップすれば「何のデータか・いつ時点か・出典」がわかる
- 仮定に基づくシミュレーション（もしも機能）は、観測モードと見た目で明確に区別する
- データの扱いは [DATA_CHARTER.md](DATA_CHARTER.md) に従う

## 最初の生き物：円目線の日本
| 部位 | データ | 頻度 |
|---|---|---|
| 触手（資金の出入り） | 財務省「対外及び対内証券売買契約等の状況」 | 週次 |
| レンズ（目線） | 円・ドル・ユーロの為替（FRB / ECB 公表値） | 日次 |

のちに ドル目線・ユーロ目線・金目線 のレンズを加え、世界へ広げる。
